# Report format

Markdown. Keep the section order; fit areas, themes, and counts to the work.

```markdown
# Shipped <START> to <END>

## Highlights

- <one sentence>. ([deploy-service#781](…), [web-console#1513](…), [OPS-123](…))
- … 3 to 5 in all

## <Area>

**<Theme>**

- …

**Engineering health**

- …

## Themes

- 2 to 4 bullets naming patterns across the period.

Left out as personal or trivial: <repos>.
```

- Rank highlights by effect on users or the business, above refactors and
  docs.
- Order areas by how much shipped.
- Themes claim only what the PR list supports.
- The left-out line is only for a work-only request.
- Write plainly: no metaphors, no intensifiers, no "just".

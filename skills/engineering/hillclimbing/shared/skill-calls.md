# Skill calls

When this skill says "call the Skill tool with `<name>`" and the harness has no Skill tool, read that skill's `SKILL.md` and follow it. The file sits wherever this skill was installed, usually beside it at `../<name>/SKILL.md`. When it is not there, the skill is not installed: apply the fallback the call states.
